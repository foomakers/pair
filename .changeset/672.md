Workflow runs take a configuration: engine, model id and effort per step, chosen with `--config`, the `workflows` key of `pair.config.json` or `--config-override`, frozen in the run (`--reconfigure` replaces it). Six shipped configurations; the key `telemetry`. The analysis script reads one run with `--run` even when another is unreadable, lists unknown token entries in a cost, and a failed run resumed without telemetry loses its closing record.
