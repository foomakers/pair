Select a workflow configuration from card labels in `pair.config.json`. An explicit `--config` wins, followed by the first matching tier in file order, the workflow configuration and the default. The CLI prints the matching tier and saves the starting labels for resume. The shipped defaults map red, yellow and green to high, medium and cheap configurations for Claude and Codex. Cards without a matching tier keep their existing configuration choice.
