Workflow profiles now resolve per-stage engines, models, effort and context across `pair run` and in-session skills. `run.defaults` and `run.agents` provide general and per-engine defaults beneath profile settings; runner commands and arguments are passed literally.

Default profiles may be selected per execution engine. Host-gap remedies preserve the selected profile and compatible engine settings.

Fresh dataset installs include six Claude/Codex profiles and seed per-engine medium defaults. Existing project config and customized profiles are preserved on install/update.
