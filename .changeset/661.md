`pair run` telemetry traces every step live (#661): a `start` record before each stage spawns, an `end` with outcome, cause, duration, tokens, effective model/effort/context and cost (tokens × the price table in `automation.md` `## Telemetry`, else `not measured`), run events (`recovery-round`, `park`, `halt`, `pr-opened`), one `end` on a signal or crash, and a synthetic `lost` end for orphan stages of a dead pid at the next run. The `card` record lists each stage and totals per runner and per model across runs. `telemetry:report` is per-card by default and takes `--by run|runner|model|step|epic|engine`. Schema versioned (`schema: 2`); legacy `stage` records read as `end`.
