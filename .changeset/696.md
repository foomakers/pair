Run YAML workflows in a coding session with `/pair-workflow-run`. Interactive steps run in the conversation, ordinary steps use subagents, and gates, approvals and merges use the workflow host. Resume the same saved run in the session or terminal. The shared bundle validates and describes workflows and records measured or estimated session telemetry when enabled.
