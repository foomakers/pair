pair gives your AI coding assistant a Knowledge Base, skills and your project's decisions, so it develops software your way, from PRD to code review, in every session.

![The process lifecycle: four phases, two workflows, three modes](/diagrams/lifecycle-overview.svg)

*Figure: pair's whole flow on one picture. Phases along the ground; the refinement and delivery workflows on top; Assisted, Supervised and Autonomous are three ways to run the same thing.*

## Pick your journey

- **[Getting Started](/docs/getting-started)**: what pair is and how to install it, five to ten minutes.
- **[Process Lifecycle](/docs/process-lifecycle)**: the flow for developing with pair: phases, workflows, modes, skills, with links to the configuration and the commands.
- **[Tutorials](/docs/tutorials)**: guided end-to-end walkthroughs, first project, existing project, team, enterprise, automation (20 to 60 minutes).
- **[What's new](/docs/whats-new)**: everything new in v0.5.0, most important first.
