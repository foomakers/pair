These pages explain **how pair works** — read them when you want understanding, not step-by-step instructions.

Start with the [AI-Assisted SDLC](/docs/concepts/ai-assisted-sdlc): the problem pair solves and how structured context changes AI collaboration. The [Knowledge Base](/docs/concepts/knowledge-base) is the core artifact — the documents installed into `.pair/` that give your AI assistant persistent context. [Skills](/docs/concepts/skills) are the actions layered on top: structured instructions your assistant discovers and executes. [Adoption Files](/docs/concepts/adoption-files) record your project-specific decisions so they never drift. [Canonical States](/docs/concepts/canonical-states) is how skills reason about work-item state across any board vocabulary. [Agent Integration](/docs/concepts/agent-integration) explains the bridge pattern that connects any AI coding tool to the single source of truth. Finally, [llms.txt](/docs/concepts/llms-txt) covers the standard pair uses to make documentation and project context natively consumable by AI assistants.
