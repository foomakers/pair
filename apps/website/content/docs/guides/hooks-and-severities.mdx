---
title: Cycle Hooks and Blocking Severities
description: Run commands at stage boundaries and choose which findings block.
---

**Goal**: add deterministic hooks and set the blocking floor.

## Prerequisites

- `tech/automation.md`

## Steps

1. **Add hooks**
   - With the CLI: under `## Cycle Hooks` use `pre-<stage>`, `post-<stage>`, `pre-cycle`, `post-cycle` or `on-halt`.
   - With `/pair-assistant` (optional, Claude Code): "add a pre-verify hook that runs the tests".
2. **Check them**
   - With the CLI: `node .claude/skills/pair-workflow-cycle/scripts/cycle-hooks.mjs load <file>`.
3. **Set the floor**
   - With the CLI: `## Blocking Severities`: `Critical`, `Major` or `Minor` (default `Minor`), optional `max-dispatches`.
4. **Validate**
   - With the CLI: `node .claude/skills/pair-workflow-cycle/scripts/blocking-severities.mjs read <file>`.

## Verify

- Both scripts exit 0 and print the parsed values.
