---
title: Cycle Hooks and Blocking Severities
description: Run commands at stage boundaries and choose which findings block.
---

**Goal**: add deterministic hooks and set the blocking floor.

## Prerequisites

- `tech/automation.md`

## Steps

1. **Add hooks**
   - In your assistant: under `## Cycle Hooks` add `pre-<stage>`, `post-<stage>`, `pre-cycle`, `post-cycle` or `on-halt` bullets.
   - With `/pair-assistant` (optional, Claude Code): "add a pre-verify hook that runs the tests".
2. **Check them**
   - With pair-cli: `node .claude/skills/pair-workflow-cycle/scripts/cycle-hooks.mjs load <file>`.
3. **Set the floor**
   - In your assistant: `## Blocking Severities`: `Critical`, `Major` or `Minor` (default `Minor`), optional `max-dispatches`.
4. **Validate**
   - With pair-cli: `node .claude/skills/pair-workflow-cycle/scripts/blocking-severities.mjs read <file>`.

## Verify

- Both scripts exit 0 and print the parsed values.
