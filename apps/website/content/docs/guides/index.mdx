Each guide is one task: goal, prerequisites, numbered steps, how to verify, where to read more. For the flow these tasks belong to, read the [Process Lifecycle](/docs/process-lifecycle) first.

## The three paths

Every step names the path that applies, with the same three labels everywhere in the docs:

- **In your assistant**: a skill you invoke as a slash command in Claude Code, Codex, Cursor, pi, opencode or any tool that reads Agent Skills. This is the default path for everything after install: bootstrap, planning, refinement, implementation, review.
- **With pair-cli**: a real `pair-cli` command in a shell: `install`, `update`, `run`, `package`, `scaffold-kb`, `kb-*`. Install, update and unattended runs live here; there is no CLI command for a skill.
- **With `/pair-assistant` (optional, Claude Code)**: the one skill the Claude Code marketplace plugin ships. It runs the CLI for you and writes adoption files after showing the diff. Only listed where asking it is the thing to do; the other two paths never depend on it.
