---
title: Classify stories and use risk tags
description: Classify a story, project the result as risk tags and let tiers scale gates and review.
---

**Goal**: get a risk tier on every story and PR, and know what it changes.

## Prerequisites

- Refinement done for the story
- Tag projection declared (optional)

## Steps

1. **Declare the tag family**
   - With the CLI: add `risk` under `## Tag Projection` in `tech/risk-matrix.md`.
   - With `/pair-assistant` (optional, Claude Code): "enable risk tags".
2. **Classify during refinement**
   - With the CLI: run `/pair-process-refine-story`; it calls `/pair-capability-classify`.
3. **Tune the matrix (optional)**
   - With the CLI: add a Criticality Table or Overrides in `risk-matrix.md`.
   - With `/pair-assistant` (optional, Claude Code): shows the diff, then writes.
4. **Let the tier flow**
   - With the CLI: `publish-pr` copies the tag to the PR; the gate runs the checks for that tier.

## Verify

- The story and its PR carry a `risk:*` tag.
- An untagged PR is treated as the strictest tier.
